One sentence, at most 200 characters, explaining the modern internet to a time traveler from 1800 — built from things they already know: a road, a post office, a library.

## How it works

`main.ts` (Node 22, standard library only) assembles the sentence from three named phrases, validates it against the gate (1–200 characters, one full stop, no modern words, every load-bearing noun known in 1800), and writes exactly those bytes to `/output/entry.txt`. No network, no randomness, no clock reads — two runs write byte-identical output.
